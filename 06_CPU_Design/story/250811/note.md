# CPU 아키텍처 및 RISC-V 개요

## 1. CPU 구조 분류
### 1.1 CISC (Complex Instruction Set Computer)
- **정의**: 다양한 명령어를 포함하고 복잡한 기능을 단일 명령어로 처리하는 프로세서 구조.
- **특징**
  - 명령어 종류가 많고 복잡함.
  - 메모리 사용 효율이 높음 (과거 소형 메모리 환경에서 유리).
  - 하드웨어가 복잡하여 설계 비용 증가.
  - 예: x86, Intel, AMD
- **장점**
  - 다양한 기능을 소수의 명령어로 처리 가능.
- **단점**
  - 명령어 길이가 다양하여 파이프라인 설계가 어려움.
  - 동작 속도가 느릴 수 있음.

### 1.2 RISC (Reduced Instruction Set Computer)
- **정의**: 단순하고 적은 수의 명령어로 구성된 프로세서 구조.
- **특징**
  - 명령어 길이가 고정, 단순한 구조.
  - 대부분의 명령이 한 클럭 내에 실행 가능.
  - 예: MIPS, ARM, RISC-V
- **장점**
  - 파이프라인 처리에 유리.
  - 하드웨어 구조 단순화, 설계 용이.
- **단점**
  - 복잡한 연산은 여러 명령어 조합 필요.

---

## 2. CPU 구조 방식
- **폰 노이만 구조**
  - 프로그램과 데이터가 같은 메모리에 저장됨.
- **하버드 구조**
  - 프로그램 메모리와 데이터 메모리가 분리되어 있음.

---

## 3. RISC-V 개요
- **정의**: UC 버클리에서 개발한 무료 오픈 소스 RISC 명령어 집합 구조(ISA).
- **특징**
  - 무료, Open Source.
  - 32/64/128bit 지원.
  - 모듈화된 ISA 구조: RV32I(기본 정수), RV32M(곱/나눗셈), RV32A(원자 연산), RV32C(압축 명령) 등.
- **역사**
  - 2010년 UC 버클리 연구팀 개발.
  - 기존 MIPS 아키텍처 영향을 받음.

---

## 4. RISC-V 프로세서 구현 방식
1. **Single Cycle Processor**
   - 모든 명령어가 1 클럭 내에 실행.
2. **Multi Cycle Processor**
   - 명령어 종류에 따라 필요한 클럭 수가 다름.
3. **Pipeline 구조 CPU**
   - 명령어 단계별 병렬 처리 (성능 향상).
   - 설계 시 주의사항: 데이터/제어 해저드 처리 필요.
