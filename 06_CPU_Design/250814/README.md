## **RISC-V INSTRUCTION SET 구현**
![RISC_V_INSTRUCTIONSET](/images/RISC_V_INSTRUCTIONSET.png)
### RV32I R-TYPE Instruction Set
## 📌 형식 (32비트 인코딩)
- **opcode (R-type)**: `0110011`
- 시프트 계열에서 시프트 양은 `rs2[4:0]` 사용

---

## 📌 필드 설명
| 필드      | 비트폭 | 설명 |
|-----------|-------:|------|
| funct7    | 7      | 연산 세부 구분 (ADD/SUB, SRL/SRA 구분) |
| rs2       | 5      | 두 번째 소스 레지스터 |
| rs1       | 5      | 첫 번째 소스 레지스터 |
| funct3    | 3      | 연산 보조 구분 |
| rd        | 5      | 목적지 레지스터 |
| opcode    | 7      | 명령어 포맷 구분 (`0110011`) |

---

## 📌 명령어 표
| Mnemonic | 연산(의사코드) | funct7   | funct3 | opcode   | 비고 |
|----------|----------------|----------|--------|----------|------|
| `ADD`    | `rd = rs1 + rs2` | 0000000 | 000    | 0110011  | 32비트 wrap-around |
| `SUB`    | `rd = rs1 - rs2` | 0100000 | 000    | 0110011  | `funct7`로 ADD와 구분 |
| `SLL`    | `rd = rs1 << rs2[4:0]` | 0000000 | 001 | 0110011 | 논리 좌시프트 |
| `SLT`    | `rd = (signed(rs1) < signed(rs2)) ? 1 : 0` | 0000000 | 010 | 0110011 | 부호 비교 |
| `SLTU`   | `rd = (unsigned(rs1) < unsigned(rs2)) ? 1 : 0` | 0000000 | 011 | 0110011 | 무부호 비교 |
| `XOR`    | `rd = rs1 ^ rs2` | 0000000 | 100 | 0110011 |  |
| `SRL`    | `rd = rs1 >> rs2[4:0]` | 0000000 | 101 | 0110011 | 논리 우시프트(0 채움) |
| `SRA`    | `rd = rs1 >>> rs2[4:0]` | 0100000 | 101 | 0110011 | 산술 우시프트(부호 유지) |
| `OR`     | `rd = rs1 \| rs2` | 0000000 | 110 | 0110011 |  |
| `AND`    | `rd = rs1 & rs2` | 0000000 | 111 | 0110011 |  |

---

## 📌 코딩 팁
- `ADD/SUB`, `SRL/SRA`는 **같은 funct3** → `funct7`으로 최종 구분
- 시프트 계열에서 **유효 시프트 폭은 0–31** (`rs2[4:0]`만 사용)
- `SLT` = **부호 비교**, `SLTU` = **무부호 비교**
- `rd = x0`일 경우 연산은 수행되지만 결과는 폐기됨

---

## 📌 어셈블리 예시
```asm
add  x7, x5, x6     # x7 = x5 + x6
sub  x7, x5, x6     # x7 = x5 - x6
sll  x7, x5, x6     # x7 = x5 << (x6[4:0])
srl  x7, x5, x6     # x7 = x5 >> (x6[4:0])      ; 논리 시프트
sra  x7, x5, x6     # x7 = x5 >>> (x6[4:0])     ; 산술 시프트
slt  x7, x5, x6     # x7 = (x5 < x6) ? 1 : 0 (signed)
sltu x7, x5, x6     # x7 = (x5 < x6) ? 1 : 0 (unsigned)
xor  x7, x5, x6
or   x7, x5, x6
and  x7, x5, x6
```
