# RISC-V CPU를 향해서
* Register => RegisterFile

## 🔹 주요 이점

1. **다중 데이터 저장**  
   - 여러 변수를 동시에 저장 가능  
   - 메모리 접근 횟수 감소 → 실행 속도 향상

2. **빠른 데이터 접근**  
   - ALU와 직접 연결되어 1사이클 내 연산 가능  
   - 반복 연산, 산술 연산 시 성능 향상

3. **제어 로직 단순화**  
   - 주소 기반 접근으로 레지스터 선택 용이  
   - 레지스터 개수 확장 시에도 제어 신호 복잡도 크게 증가하지 않음

4. **코드 효율성 향상**  
   - 변수를 레지스터에 상주시켜 Load/Store 명령 감소  
   - 메모리 대역폭 절약

5. **확장성과 재사용성**  
   - 다양한 설계(연산기, 마이크로컨트롤러 등)에 재사용 가능  
   - Verilog/VHDL 설계에서 모듈화 용이

## 📊 비교 요약

| 항목               | 단일 Register | Register File |
|--------------------|--------------|---------------|
| 저장 가능 변수 수  | 1            | 다수          |
| 접근 속도          | 빠름         | 빠름 (동일)   |
| 병렬 읽기/쓰기     | 불가능       | 가능          |
| 제어 신호 복잡도   | 낮음         | 보통          |
| 확장성             | 낮음         | 높음          |
| 메모리 접근 필요성 | 많음         | 적음          |

💡 **결론:**  
Register File은 연산 효율, 확장성, 코드 효율성을 동시에 개선하는 핵심 구조
