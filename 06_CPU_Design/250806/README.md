### ***Review duration***
* updowncounter(0~9999)
### Spec
```
Up/down Counter

Mode 0 : up counter
Mode 1 : down counter

0.1초 간격으로 Counting 동작,
FND에 숫자를 출력 (00000 ~ 99999)

전원이 인가되면 Mode에 맞게 Counting 동작,
mode 버튼을 눌러서 전환 → up → down
             down → up

mode 버튼 1개로 동작, mode이 toggle.
```
