## 📁 프로젝트 디렉토리 구성
| 폴더명                         | 내용 설명                                                              |
| --------------------------- | ------------------------------------------------------------------ |
| `01_Embedded_SW`            | STM32 등 임베디드 시스템 기반의 임베디드 소프트웨어 프로젝트를 포함합니다.                 |
| `02_Semi_Design`            | Verilog를 활용한 RTL 설계 및 다양한 시뮬레이션를 정리했고, 그에 관한 프로젝트 내용이 포함되어 있습니다..        |
| `03_SystemOnChip`           | SoC(System on Chip) 관련 설계 프로젝트로, IP 통합 및 통신 구조 설계 등을 다루는 프로젝트 내용이 포함되어 있습니다.       |
| `04_PhysicalDesign`         | 실제 칩 제작 단계에 가까운 물리적인 설계 과정을 다룹니다. EDA 툴 기반의 작업 내용이 포함되어 있습니다.         |
| `05_AI_Algorithm&structure` | AI 및 머신러닝 관련 알고리즘 구현 및 구조 설계 프로젝트가 포함되어 있습니다. (ex. 얼굴 인식, 시선 추적 등) |
| `06_CPU_Design`             | RISC-V 기반의 32bit CPU를 직접 설계하고 시뮬레이션한 프로젝트 내용이 포함되어 있습니다.                  |
| `250620`                    | PWM를 Verilog로 제어하여 전자레인지 시스템을 제작한 프로젝트 내용이 포함되어 있습니다.          |
| `FINAL_PROJECT`             | VGA를 활용한 인생네컷 시스템을 제작한 최종 프로젝트 내용이 포함되어 있습니다.                  |
