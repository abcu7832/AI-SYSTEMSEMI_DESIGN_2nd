# 🧠 AI Semicon 4 Cut

> 반도체 기반 인공지능 시스템을 구성하는 최종 프로젝트입니다.  
> UVM 기반 검증 환경과 RTL 소스, 제약 파일, 발표 자료까지 포함되어 있습니다.

## 📁 프로젝트 구조

```bash
.
├── UVM/                  # UVM 기반 시뮬레이션 및 검증 환경
├── constrs_1/            # 타이밍 제약 파일 (XDC 등)

├── Final_최종 발표 버전.pdf  # 최종 프로젝트 발표자료

```

📌 프로젝트 개요

* 프로젝트명: AI Semicon 4 Cut
* 목표: 반도체 설계와 AI 시스템을 결합한 SoC 아키텍처 설계 및 검증
* 주요 키워드: FPGA, RTL Design, UVM Verification, Timing Constraints, AI Accelerator

🔧 사용 기술

* SystemVerilog 기반 RTL 설계 및 검
* Xilinx Vivado (Simulation, Synthesis)
* Verdi (Waveform Debugging)
