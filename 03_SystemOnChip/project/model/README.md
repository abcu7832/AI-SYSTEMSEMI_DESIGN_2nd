# MATLAB FFT Model

512-point FFT의 floating / fixed 모델과 보조 함수 모음입니다.

## 📂 Files

- **fft_float.m** : 부동소수점 FFT 참조 모델
- **fft_fixed.m** : 고정소수점 FFT 모델 (스케일링·라운딩·포화 포함)
- **saturation.m** : 포화 연산 처리
- **mag_detect.m** : 크기(헤드룸) 검출
- **min_detect.m** : 최소비트(헤드룸) 탐지
- **dec_to_bin.m** : 10진수를 2진 문자열로 변환
